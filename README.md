# L431 电源管理

## 当前范围

当前 PCB 只焊接了 `AMMO` 一路，因此现在整板的电源管理都通过 `AMMO` 这一路完成。
`GIMBAL`、`CHASSIS`、`MINI-PC` 三路在本板上不参与控制。

## 当前行为

- 上电后固定打开 `AMMO`
- 当前没有自动翻转任务
- ADC 只读取 `AMMO` 电流检测通道，采样频率为 `1 KHz`
- 串口通过 `LPUART1` 每 `100 ms` 打印一次平均功率、峰值功率和电流值
- 功率单位为 `W`，功率上限由 `APP_POWER_LIMIT_W` 配置，超限后触发 `APP_Power_OverLimitCallback()`

## 硬件事实

- MCU：`STM32L431RCT6`
- `AMMO` 开关管控制脚：`PC6 / INT-AMMO`
- `AMMO` 电流检测输入：`PA5 / AMMO-U / ADC1_IN10`
- 电流检测芯片：`INA180A2IDBVR`
- INA180 增益：`50 V/V`
- 采样电阻：`4 mΩ`
- LPUART1：`115200，8N1`

## 电流换算

理想关系：

```text
VOUT = I × 0.004 Ω × 50
     = I × 0.2 V

I(mA) = VOUT(mV) × 5
```

按 12 位 ADC、`VDDA = 3.3 V` 计算时：

```text
VOUT(mV) = adc_raw × 3300 / 4095
I(mA)    = VOUT(mV) × 5
```

当前功率计算按 `11.98 V` 总线电压换算为整数 `W`。
