# 电管串口通信命令

## 串口参数

LPUART1，PC0 为 RX，PC1 为 TX；`115200, 8N1`，无硬件流控。消息为 ASCII 文本行，以 `\r\n` 结束；接收端也兼容只发送 `\n`。

## 命令

| 命令 | 作用 | 响应 |
| --- | --- | --- |
| `PING` | 通信测试 | `PONG` |
| `PWR=<W>` | 设置底盘功率限制，1–1000 W | `ACK,PWR,OK/ERR` |
| `BUF=<J>` | 设置剩余缓冲能量，0.0–20.0 J | `ACK,BUF,OK/ERR` |
| `CUR=<mA>` | 设置过流阈值，0–16500 mA；0 关闭 | `ACK,CUR,OK/ERR` |
| `REQ,CHS,ON` | 通过自检后请求打开底盘 | `ACK,CHS,OK/ERR` |
| `REQ,RSV,ON` | 请求打开预留通道，当前拒绝 | `ACK,RSV,ERR` |
| `SW,CHS,ON/OFF` | 调试强制底盘开关 | `ACK,CHS,OK/ERR` |
| `SW,RSV,ON/OFF` | 调试设置预留开关状态 | `ACK,RSV,OK/ERR` |
| `STA=ON/OFF` | 开启/关闭 10 Hz 状态上报，默认关闭 | `ACK,STA,OK/ERR` |
| `GET=STA` | 获取最近一次 100 ms 结算状态 | `ACK,STA,OK/ERR` 后跟状态帧 |
| `GET=RAW` | 获取当前 ADC/电流/功率和 ADC 计数 | `ACK,RAW,OK` 后跟 RAW |

所有命令均需追加 `\r\n`。例如：`STA=ON\r\n`。

通信测试：发送 `PING\r\n`，返回 `PONG\r\n`。

## 10 Hz 状态帧

开启后每 100 ms 发送：

```text
STA,PAVG=<W>,IAVG=<mA>,OV=<0/1>,SAT=<0/1>,CUT=<0/1>,OCP=<0/1>,BUF=<J>,LIM=<W>,CUR=<mA>,CHS=<ON/OFF>,RSV=<ON/OFF>,FIRE=<ON/OFF>\r\n
```

`PAVG`、`IAVG` 是本结算周期平均功率和平均电流；`BUF` 范围为 0.0–20.0 J；`CUT=1` 表示功率惩罚断电期；`OCP=1` 表示 4 A、连续 200 ms 过流保护已锁存；`FIRE=OFF` 时主控必须禁止发射。

## 发射许可事件

保护状态变化时，电管主动发送以下事件，主控无需回复 ACK，应立即执行：

```text
FIRE=OFF\r\n
FIRE=ON\r\n
```

`FIRE=OFF` 时主控禁止发射；保护解除且底盘满足恢复条件后发送 `FIRE=ON`。主控应同时使用状态帧中的 `FIRE` 做状态同步。

## 调试读取示例

```text
RAW,ADC=1139,I=4585,P=54,AST=1000,AOK=1000,AERR=0,SAT=0\r\n
```
